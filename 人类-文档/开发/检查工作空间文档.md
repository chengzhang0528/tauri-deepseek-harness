# 检查工作空间文档

修改本仓库文档后，用本页检查结构、引用和入口是否有效。

1. 在 `tauri-deepseek-harness` 仓库根目录打开 PowerShell，运行：

   ```powershell
   npm run check:docs
   ```

   退出码为 `0` 且输出 `Documentation check passed` 表示机器检查通过；这不证明产品描述与当前实现一致。

2. 若失败，按输出中的文件路径修正对应文档。位置、类型和状态规则见[工作空间结构契约](../../文档/WORKSPACE_STRUCTURE.md)。修复后可重复运行同一命令。

3. 从[人类文档入口](../README.md)打开修改过的页面，核对步骤、命令和预期结果；产品描述还需与其链接的正式事实及实现核对。
